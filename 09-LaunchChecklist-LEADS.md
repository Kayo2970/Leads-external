# Launch Checklist
**LEADS Next Gen Centre** · v1.0 · A fully ticked checklist IS the sign-off to go live.

*Assumptions: this is a brand-new site (no prior public URLs to redirect). Target launch window is approximately one month from project kickoff — confirm the exact date before Section 1. Emergency contact to be filled in by the team.*

---

## 1. Launch Basics

- [ ] Confirmed exact launch date: ______________
- [ ] Soft launch planned first (site live, not yet publicly promoted) — **recommended and included**
- [ ] Public announcement plan confirmed (e.g. LinkedIn/Instagram posts, email, WhatsApp broadcast)
- [ ] Emergency contact on launch day: Name: ______________ Phone/Email: ______________

## 2. Content Checks (per page, from the Sitemap)

- [ ] Home — final copy in place, no placeholder text, hero stat verified accurate
- [ ] Events — all launch events have final names, descriptions, and logos (no "TBD" artwork)
- [ ] About Us — Leadership/Board of Members section has final names, titles, and photos (or approved placeholders)
- [ ] Reports — all launch-ready PDF reports uploaded and download-tested
- [ ] Contact Us — form fields finalised and tested end-to-end
- [ ] Every page: title tag and meta description set (no defaults left in)
- [ ] Every image has descriptive alt text
- [ ] No broken internal or external links (including BLS and LEADS Portal links)

## 3. Form Testing

- [ ] Contact form submits successfully with valid data
- [ ] Contact form shows a clear error for invalid/missing required fields
- [ ] Submission successfully reaches the confirmed destination (inbox/spreadsheet/CRM — per Open Question in PRD)
- [ ] Confirmation message or thank-you state shown to the visitor after submitting

## 4. Cross-Device & Cross-Browser Testing

- [ ] Desktop — Chrome
- [ ] Desktop — Safari
- [ ] Desktop — Firefox
- [ ] Mobile — iOS Safari
- [ ] Mobile — Android Chrome

## 5. Interactive Elements

- [ ] Event pop-ups open and close correctly on all devices (including via Escape key and outside-click)
- [ ] Reports dropdown opens correctly and every report link downloads the correct file
- [ ] Light/dark mode toggle works correctly and preference is remembered on return visits
- [ ] BLS and LEADS Portal links open in a new tab and go to the correct external destination

## 6. Performance & Technical Checks

- [ ] Site loads quickly on both desktop and mobile connections
- [ ] Animated hero background (Threads) runs smoothly and pauses correctly when the tab isn't visible
- [ ] Reduced-motion setting correctly shows a static version of the background
- [ ] No console errors on any page
- [ ] SSL/HTTPS active (once on a public domain)

## 7. SEO & Analytics

- [ ] Google Analytics 4 installed and confirmed tracking (real-time report)
- [ ] Google Search Console verified and sitemap.xml submitted
- [ ] robots.txt configured correctly
- [ ] Google Tag Manager installed with GA4 + Hotjar tags firing correctly

## 8. Legal & Trust

- [ ] Privacy Policy published and linked (required — lead form collects personal data)
- [ ] Terms & Conditions published and linked
- [ ] Cookie consent notice included if analytics cookies are used *(recommended, not mandatory)*

## 9. Sign-Off

- [ ] Developer(s) on standby for the first day after launch
- [ ] Both team and developer(s) hold independent admin/hosting credentials
- [ ] All items above checked → **this checklist itself is the approval to go live**

*Re-run this full checklist at every major site update.*
